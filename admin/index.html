Phone alerts

A notification on the team's phones the moment a website order comes in. Each person turns alerts on in Ops → Orders. A small Google script on this account sends them. Set it up once:

  1. Easiest on a computer. Signed in as spartanbiolabs.info@gmail.com, open script.google.com → New project. Tap the name Untitled project at the top and rename it Spartan Ops Alerts.
  2. In Code.gs, select everything and delete it. Tap Copy the script below, paste it in, then tap 💾 Save and wait until "Unsaved changes" at the top goes away.
  3. ⚙ Project Settings (left side) → tick Show "appsscript.json" manifest file in editor. Go back to the editor (< > on the left), open appsscript.json, select everything and delete it, then paste Copy the settings file (it's one long line) and 💾 Save.
  4. In the toolbar right above the code, next to ▷ Run, there's a dropdown showing myFunction or doGet. Pick setup in it, then tap ▷ Run. Google asks for permission: Review permissions → your account → Advanced → Go to Spartan Ops Alerts (unsafe) → Allow. It's your own script. Done when the log at the bottom says Ready.
  5. Deploy → New deployment → ⚙ next to "Select type" → Web app. Execute as Me, Who has access Anyone → Deploy. Copy the Web app URL, paste it below, tap Save link, then Check.
